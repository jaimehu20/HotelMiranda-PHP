⚡ FUNCIONALIDADES ⚡

-  Habitaciones disponibles: En la página inicial, si introduces un rango de fechas concreto, puedes comprobar si hay habitaciones disponibles para reservar.
-  Listado de habitaciones: En la página Rooms, se muestra un listado de habitaciones que se obtiene de una base de datos en MySQL.
-  Reservas: Es posible entrar en las habitaciones disponibles, de forma individual, y a través de un formulario, realizar la reserva de la misma.
-  Formulario: En la página Contact, se puede contactar con el hotel a través de un formulario.

  La finalidad de este proyecto es dar mis primeros pasos en PHP y Laravel. He utilizado como base mi anterior proyecto, en el que solo me encargué de maquetar la página web y ahora, utilizando PHP, simular el funcionamiento real de la web del hotel, aceptando reservas, consultas sobre fechas y poder visualizar las diferentes habitaciones.
